## 🎨 UI 구성 요소

### 1. 헤더
- **제목**: 📊 Dataset Explorer
- **카테고리 선택**: Dropdown (bottle, cable, capsule)

### 2. 통계 카드 (3개)
```
┌─────────────┬─────────────┬─────────────┐
│ 📦 Training │ ✅ Test Good│ ❌ Test Def │
│ 209 images  │ 20 images   │ 63 images   │
└─────────────┴─────────────┴─────────────┘
```
- **Training**: 학습용 정상 이미지 개수
- **Test Good**: 테스트 정상 이미지 개수
- **Test Defects**: 테스트 결함 이미지 개수

---

### 3. Training Data 섹션

#### 그리드 구조
```
5열 × 1행 = 5개 이미지 (한 번에 표시)
```

#### 각 이미지 카드
- 이미지 썸네일
- 파일명 표시 (예: 000.png → "000")
- 클릭 시 상세보기 모달 열림

#### 네비게이션 버튼
```
[◀]  ┌────┬────┬────┬────┬────┐  [▶]
     │Img │Img │Img │Img │Img │
     ├────┼────┼────┼────┼────┤
     │000 │001 │002 │003 │004 │
     └────┴────┴────┴────┴────┘

Showing 1-5 of 209
```
- **좌측 버튼 [◀]**: 4개씩 왼쪽으로 이동
- **우측 버튼 [▶]**: 4개씩 오른쪽으로 이동
- **중복 표시**: 마지막 이미지가 다음 페이지의 첫 이미지로 중복

**페이지 이동 예시:**
```
1-5 of 209  →  [▶]  →  5-9 of 209  →  [▶]  →  9-13 of 209
            ←  [◀]  ←             ←  [◀]  ←
```

---

### 4. Test Data 섹션

#### 그리드 구조 (2행, 수직 정렬)

**상단 행: 테스트 이미지 (5×1 그리드)**
```
[◀]  ┌────┬────┬────┬────┬────┐  [▶]
     │ ✅ │ ❌ │ ❌ │ ✅ │ ❌ │
     │Img │Img │Img │Img │Img │
     ├────┼────┼────┼────┼────┤
     │000 │001 │002 │003 │004 │
     └────┴────┴────┴────┴────┘
```
- Good: 초록 체크 ✅
- Defect: 빨간 X ❌ (결함 타입명 표시)

**하단 행: Ground Truth (5×1 그리드, 수직 정렬)**
```
     ┌────┬────┬────┬────┬────┐
     │N/A │ GT │ GT │N/A │ GT │
     │    │Mask│Mask│    │Mask│
     ├────┼────┼────┼────┼────┤
     │-   │001 │002 │-   │004 │  ← 파일명 (GT만)
     └────┴────┴────┴────┴────┘
```
- Good: "N/A" 회색 박스 (GT 없음)
- Defect: 흰색 마스크 이미지 + 🎯 GT 표시
- **네비게이션**: 상단 Test 이미지 버튼과 자동 동기화 (버튼 없음)

#### 네비게이션 버튼 (Test 이미지만)
```
Showing 1-5 of 83
```
- **좌측 버튼 [◀]**: 4개씩 왼쪽으로 이동
- **우측 버튼 [▶]**: 4개씩 오른쪽으로 이동
- **중복 표시**: 마지막 이미지가 다음 페이지의 첫 이미지로 중복
- **자동 동기화**: Test 이미지 이동 시 GT도 자동으로 함께 이동 (수직 정렬 유지)

**페이지 이동 예시:**
```
1-5 of 83  →  [▶]  →  5-9 of 83  →  [▶]  →  9-13 of 83
           ←  [◀]  ←            ←  [◀]  ←
```

## 📋 UI 동작 흐름

### Training Data
1. 카테고리 선택 (bottle/cable/capsule)
2. 5×1 그리드에 5개 이미지 표시
3. [◀] [▶] 버튼으로 4개씩 이동 (마지막 이미지 중복)
4. Showing 범위 표시 (예: 1-5 of 209)
5. 이미지 클릭 → 상세보기 모달

### Test Data
1. 카테고리 선택 (bottle/cable/capsule)
2. 상단 5개: 테스트 이미지 (Good ✅ / Defect ❌)
3. 하단 5개: Ground Truth (수직 정렬)
4. [◀] [▶] 버튼으로 4개씩 이동 (Test + GT 동기화)
5. Showing 범위 표시 (예: 1-5 of 83)
6. 이미지 클릭 → 상세보기 모달

### 상세보기 모달
1. 이미지 클릭 시 전체 화면 모달 열림
2. 슬라이더로 줌 조정 (25~300%)
3. 드래그로 이미지 이동
4. 스크롤로 줌 인/아웃
5. 더블클릭으로 100% 리셋
6. ESC 또는 [✕]로 닫기

## 🔗 백엔드 API 요구사항

### 필요한 API

#### 1. GET /api/datasets
```json
["bottle", "cable", "capsule"]
```

#### 2. GET /api/dataset/{category}
```json
{
  "category": "bottle",
  "train_count": 209,
  "test_good_count": 20,
  "test_defect_count": 63,
  "defect_types": [
    {"name": "broken_large", "count": 21},
    {"name": "broken_small", "count": 21},
    {"name": "contamination", "count": 21}
  ]
}
```

#### 3. GET /api/images/{category}/{type}
```json
{
  "images": ["000.png", "001.png", ...],
  "total": 209
}
```
- type: "train/good", "test/good", "test/broken_large", etc.

#### 4. GET /api/image/file/{category}/{type}/{filename}
- FileResponse (이미지 파일)

#### 5. GET /api/ground-truth/{category}/{type}/{filename}
- FileResponse (GT 마스크 이미지)
- 파일명: 000.png → 000_mask.png

## 📚 참고사항

### 이미지 네비게이션 동작

**페이지 이동 로직:**
```javascript
// 초기 상태
currentPage = 0  // 이미지 0~4 표시
displayedImages = images.slice(0, 5)

// [▶] 클릭 (오른쪽으로 4개 이동)
currentPage = currentPage + 4  // 4~8 표시
displayedImages = images.slice(4, 9)

// [▶] 클릭
currentPage = 8  // 8~12 표시
displayedImages = images.slice(8, 13)

// [◀] 클릭 (왼쪽으로 4개 이동)
currentPage = 4  // 4~8 표시
displayedImages = images.slice(4, 9)
```

**중복 표시:**
- 마지막 이미지가 다음 페이지의 첫 이미지로 중복
- 사용자가 현재 위치 파악 용이
- 연속성 제공

**버튼 비활성화:**
```javascript
// 왼쪽 버튼
disabled = currentPage === 0

// 오른쪽 버튼
disabled = currentPage + 5 >= images.length
```

**Test Data 동기화:**
- Test 이미지에만 [◀] [▶] 버튼 존재
- 버튼 클릭 시 Test와 GT가 자동으로 함께 이동
- Test와 GT의 수직 정렬 항상 유지
- 동일한 currentPage 상태 공유

### MVTec AD 데이터 구조
```
mvtec_ad/
└── bottle/
    ├── train/
    │   └── good/          (209 images)
    ├── test/
    │   ├── good/          (20 images)
    │   ├── broken_large/  (21 images)
    │   ├── broken_small/  (21 images)
    │   └── contamination/ (21 images)
    └── ground_truth/
        ├── broken_large/  (21 masks: *_mask.png)
        ├── broken_small/  (21 masks)
        └── contamination/ (21 masks)
```

### Ground Truth 특징
- **형식**: PNG 이미지 (그레이스케일)
- **내용**: 
  - 검은색 (0): 정상 영역
  - 흰색 (255): 결함 영역
- **파일명**: 원본.png → 원본_mask.png
- **존재**: 결함 이미지에만 (good 이미지는 없음)
